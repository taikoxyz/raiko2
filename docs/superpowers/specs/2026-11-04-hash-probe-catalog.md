## Hash utility

`F(x,y)=low64(x*y) XOR high64(x*y); A=F(k0 XOR S,k1 XOR G); H=F(k2 XOR A,k3 XOR G)`.

`hash --seed HEX64 --shared HEX64 --key HEX256 ...` accepts1..1024 repeated keys and emits bounded JSON containing exact canonical keys/full64-bit hashes in input order. Scalars and keys use lowercase `0x` plus16/64 hex digits. No floating conversions. Reject duplicate scalar/unknown/missing flags and malformed/domain input before output. This mode supports independent comparison against all512 actual captured cold-key hashes, rather than testing only the query.

Query has zero low192 bits and eight nonzero high64 bytes. Candidate keys keep query's low224 bits, varying only the highest32 bits; reject zero high-byte candidates, the query and duplicates, and append the fixed query last. This preserves16KiB calldata and its zero/nonzero byte counts while giving long equal key prefixes.
