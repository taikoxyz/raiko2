## Exact inputs and finite gas domain

Two signed users call distinct authenticated code accounts with empty persistent storage and distinct fixed-width owner tags 0/1. Call i hashes `BE256((tag<<128)|i) || pattern_byte*(L-32)` for i=0..R-1. All input byte strings are unique across both users within a proposal. Different code hashes are intentional. Empty outer calldata, no storage operations, no refunds and no creation keep this a selected SHA-256/memory/copy/dispatch fixture.

The runtime seeds the input once and uses logarithmic MCOPY doubling for both tails, even at R0. Counter and XOR accumulator occupy words 0/32; input begins at 64 and output at 64+L, for `3+L/32` memory words. Output sentinel 2 is reset before each STATICCALL. Guards require status 1, returndata length 32, exact final XOR and counter, then STOP. The XOR is noninjective; an independent actual-byte interpreter checks every ordered input and returned digest (202,364 calls across the 18 selected two-user programs), plus copy, memory, opcode counts, control flow, forwarding, returned gas and guards. It does not infer execution intent from XOR alone.

Native SHA-256 gas is `60+12*ceil(L/32)`, with warm STATICCALL access 100 charged separately. Memory expansion is `3*w+w*w//512`, MCOPY is `3+3*ceil(n/32)`, and intrinsic gas is 21000. These rules agree with the frozen revm-precompile 41.0.0 source and the primary [SHA-256 execution specification](https://ethereum.github.io/execution-specs/src/ethereum/forks/berlin/vm/precompiled_contracts/sha256.py.html) and [EIP-5656](https://eips.ethereum.org/EIPS/eip-5656). Requested GAS is constrained by EIP-150 and unused child gas returns to the caller.

## Interpretation and remaining work

Prices remain unchanged. Preserve all absolute deficits, signed pattern differences and exact incremental comparisons. The frozen high priority remains positive actual-minus-node >2B PGU within <=30M charged gas. Smaller gaps remain explicit refinements; startup-scale resemblance does not causally assign their cost. Very conservative quotes can reject useful work, and selected synthetic coverage does not certify ordinary historical usability or select an admission limit.

Coverage improves only for these exact unique-input schedules, tails, lengths, successful calls and uniform repetition. Arbitrary messages, general cache behavior, the unmeasured floor/linear boundary and larger lengths, malformed/failure paths, deeper call composition and heterogeneous packing/order remain open.
