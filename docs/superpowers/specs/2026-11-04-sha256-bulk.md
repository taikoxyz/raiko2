## Scope and selected design

Add an offline compiler-free fixture producer and independent bounded actual-byte oracle for SHA-256 precompile0x02. Sample 18 prospective inputs: tail pattern zero/a5 × exact input lengths64/4096/1048576 bytes × own-zero/single/maximal-uniform-full. Two signed users each call a distinct authenticated code account with empty persistent storage; owner index tag0/1 is embedded with fixed PUSH32 width. Each user has a fixed runtime per selected row. Different code hashes are intentional, so this is not a shared-code experiment.

Each call hashes `BE256((tag<<128)|i) || pattern_byte*(L-32)` for i=0..R-1. Inputs are unique across calls/users in one proposal; do not repeat a fixed all-zero buffer and then claim general cache coverage. Outer calldata empty. Build a pattern-filled input once using one MSTORE and logarithmic MCOPY doubling for both patterns, then replace its first word before each call. MCOPY runs even for zero controls. Counter word0, XOR accumulator word32, input offset64, output64+L. Total memory words3+L/32. Preallocate output to sentinel2, reset2 before every call. Require success1 and returndata32. XOR each returned digest into accumulator, check final exact precomputed XOR and counter before STOP. Expected output XOR is a guard, not a collision-free description of an execution: independent oracle must check every call's actual ordered byte string and returned digest, plus aggregate. Zero control sentinel remains2 and counter/accumulator0. All user receipts and Anchor successful. No storage/refunds/creation.

Use existing _Factory and existing original request schema; old helpers/oracles remain byte unchanged. Fixed-width immediates keep code-size/opcode count stable when changing count/tag/pattern/expectedXOR. Domain validation excludes bool-as-int, bad levels/patterns/lengths/tags. Code stays below24576 bytes. Avoid expensive digest computation while gas-accounting/binary-searching huge candidate R: a fixed-width assembly placeholder is allowed only for gas sizing, never emitted in a selected request. Real selected runtimes contain correct expected XOR computed with stdlib hashlib; all emitted requests need independent full byte-oracle qualification.

Warm STATICCALL adds100; requested GAS value is capped by actual EIP150 available gas, unused child gas returned. Count all ordinary ops, memory expansion `3*w+w*w//512`, MSTORE, MCOPY `3+3ceil(n/32)`, intrinsic21000 and postcall control flow. No payload floor with empty calldata, no refund. Choose fixed reserve `ceil(native_gas/63)+2301` beyond gross for continuation; label as fixture policy, not protocol/SSTORE requirement. 15M/user fixture cap separate from EIP7825=16777216, 31M header,30M charged block incl167355 Anchor; every ordered admission prefix enforced.
